# HauntShell Digital Artifact Explorer

This example demonstrates the "HauntShell" concept by simulating interaction with "dead technologies" or "digital artifacts". It provides a simple command-line interface to list, load, and read the contents of predefined old system logs, configurations, and game scores, mimicking the idea of "digital archaeology" and "reviving lost digital spirits".

## Language

`python`

## How to Run

Save the code as `hauntshell.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python hauntshell.py`. Follow the on-screen instructions.
